## 📌 Projetos em destaque

### 🎵 SpotMusic

Aplicação web para criação de playlists e avaliação de músicas.

**Tecnologias:**  
Java • Spring Boot • Thymeleaf • MySQL • HTMX • Docker

**Destaques do projeto:**
- Cadastro e gerenciamento de playlists
- Cadastro e avaliação de músicas
- Persistência com MySQL
- Validação de dados
- Deploy em ambiente cloud
- Navegação parcial com HTMX
- Player que continua ativo durante a navegação

🔗 [Acessar repositório](https://github.com/RafaelWillian91/Project-Spring-SpotMusic)
